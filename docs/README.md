# 📚 مستندات پروژهٔ «ar» — راهنمای کامل Rust به فارسی

سلام! این پوشه یک **راهنمای فارسی از صفر تا حرفه‌ای برای Rust** است که موازی با
کد واقعی همین مخزن نوشته شده. هرچه در این مستندات می‌بینی، در پوشهٔ `src/`
معادل اجراشدنی دارد:

```bash
ar demo all      # هر موضوع مستندات، یک دموی اجراشدنی
```

## 🎯 مسیرهای مطالعه

### مسیر ۱ — تازه‌کار مطلق (۲–۳ هفته)
```
۰۰ → ۰۱ → ۰۲ → ۰۳ → ۰۴ → ۰۵ → ۰۶ → (تمرین: rustlings) → ۱۲ (مرور ترفندها)
```

### مسیر ۲ — برنامه‌نویس زبان‌های دیگر (۱ هفته فشرده)
```
۰۲ (مرور سرسری) → ۰۳ (دقیق!) → ۰۴ → ۰۵ → ۰۶ → ۱۳ (دام‌ها) → ۱۵ (چیت‌شیت)
```
🎯 تمرکز روی «مالکیت» و «قرض» — تنها بخشی که در JS/Python/Java معادل ندارد.

### مسیر ۳ — حرفه‌ای‌شدن (۲–۴ هفته)
```
۰۷ → ۰۸ → ۰۹ → ۱۰ → ۱۱ → ۱۴
```
به‌همراه کد خواندن: `src/web.rs` (سرور دست‌ساز)، `src/store.rs` (ذخیرهٔ اتمیک)،
`src/demos/` (۱۵ دمو).

### مسیر ۴ — فقط نگاه سریع
```
۱۲ (۱۰۰ ترفند) + ۱۵ (چیت‌شیت) + ۱۷ (واژه‌نامه)
```

## 🔗 نسبت مستندات با کد

| سند | کد مربوطه |
|-----|-----------|
| ۰۲ نحو | `src/cli.rs` (پارسر دستی با پیمایش اندیس) |
| ۰۳ مالکیت | `src/app.rs` (برش‌های `&str`، عمر برش‌ها) |
| ۰۴ انواع/trait | `src/model.rs` (`Priority`), `src/store.rs` (`trait Store`) |
| ۰۵ خطاها | `src/errors.rs` (`AppError`)، `main.rs` (کد بازگشتی) |

| ۰۷ اشاره‌گرها | `src/store.rs::open_store` (`Box<dyn Store + Send>`)، `src/web.rs` (`Arc<Mutex<…>>`) |
| ۰۸ هم‌روندی | `src/web.rs` (ترد به‌ازای هر اتصال) |
| ۰۹ async | «قدم بعدی» پروژه (دموی پیشنهادی در خود سند) |
| ۱۰ ماکرو | `src/demos/macros_demo.rs` (ماکروی تولید تست) |
| ۱۱ unsafe | `src/demos/unsafe_ffi.rs` (اشاره‌گر خام + پوشش امن) |
| ۱۲–۱۷ | سراسر پروژه |

## 🧪 تست و تأیید

```bash
cargo test        # همهٔ تست‌ها (واحد + دموها)
cargo build       # باید صفر هشدار بدهد
ar demo all       # ۱۵ دموی اجراشدنی
ar serve --port 8080   # سرور وب با رابط فارسی
```
