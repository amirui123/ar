# 📖 ۱۷ — واژه‌نامهٔ فارسی–انگلیسی Rust

> هر اصطلاح را با یک جمله توضیح داده‌ایم. عادت کن به **انگلیسی** فکر کنی ولی
> فارسی توضیح بدهی — اینطور در مستندات و انجمن‌ها گم نمی‌شوی.

---

## الف) مالکیت و حافظه

| انگلیسی | فارسی | یک‌خطی |
|---------|-------|-------|
| ownership | مالکیت | هر مقدار یک مالک دارد؛ با مرگ مالک، مقدار آزاد می‌شود |
| borrow | قرض‌گرفتن | گرفتن `&`/`&mut` بدون انتقال مالکیت |
| borrow checker | بررسی‌کنندهٔ قرض | کامپایلری که قواعد را چک می‌کند |
| lifetime | طول عمر | بازهٔ اعتبار مرجع؛ با `'a` نشان داده می‌شود |
| move | انتقال | مالکیت به جای دیگری می‌رود |
| copy | کپی | نوع `Copy` بیت‌به‌بیت کپی می‌شود |
| clone | همتاسازی | کپی صریح و (معمولاً) عمیق |
| dangling | معلق | اشاره‌گر به حافظهٔ آزادشده |
| UB (undefined behavior) | رفتار تعریف‌نشده | کامپایلر هیچ تضمینی ندارد — بدترین حالت |
| memory leak | نشت حافظه | آزاد نشدن حافظه (Rust جلویش را نمی‌گیرد) |
| drop | آزادسازی | تابع مقصد آزادسازی مقدار |
| RAII | منبع با طول عمر شیء | آزادسازی خودکار در پایان محدوده |
| stack / heap | پشته / کپه | حافظهٔ سریع با محدوده / حافظهٔ بزرگ‌تر و پویا |
| zero-cost abstraction | انتزاع بدون هزینه | کد سطح‌بالا که مثل کد سطح‌پایین اجرا می‌شود |
| niche optimization | بهینه‌سازی نیش | استفاده از حالت‌های غیرممکن یک نوع (مثل `Option<&T>` ۸ بایتی) |

| انگلیسی | فارسی | یک‌خطی |

## ح) جملات کلیدی که باید بلد باشی

* «**Move semantics** = پس از انتقال، متغیر دیگر معتبر نیست.»
* «**Borrow checker** جلوی داده‌ی رقابتی را در زمان کامپایل می‌گیرد.»
* «`&mut` هم‌زمان با هر مرجع دیگری **ممنوع** است.»
* «`unsafe` بررسی قرض را **خاموش نمی‌کند**؛ فقط چهار قدرت اضافه می‌دهد.»
* «`async fn` بدون اجراکننده **هیچ کاری نمی‌کند**.»
* «`Rc` نه `Send` است نه `Sync`؛ برای تردها `Arc`.»
* «`format!` جداکنندهٔ هزارگان **ندارد**.»
* «`len()` روی `str` = بایت، نه کاراکتر.»
* «هر `unwrap` = یک پنیک بالقوه؛ در کتابخانه، `Result` برگردان.»
* «بهینه‌سازی پیش از **اندازه‌گیری**، هزینه‌ی بی‌فایده است.»
