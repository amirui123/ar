# 🧠 آزمایشگاه زنده هوش مصنوعی و یادگیری ماشین (NeuroMount AI Studio)

یک پلتفرم تعاملی و زنده برای تجربه واقعی **یادگیری ماشین (Machine Learning)**، **آموزش مینی LLM** و **سوار کردن شبکه عصبی روی ایجنت‌های خودران** به همراه خروجی کد **Rust**.

## ✨ امکانات اصلی

1. **💬 مینی LLM و چت‌بات خودآموز (Live-Learning Language Model):**
   - آموزش زنده توکن‌به‌توکن با گرادیان کاهشی روی متن و دیالوگ‌های دلخواه شما
   - نمایش زنده کاهش خطا (**Cross-Entropy Loss**) و افزایش دقت در هر **Epoch**
   - **یادگیری آنی در چت (Online Fine-Tuning):** تزریق مستقیم سوال و جواب جدید به حافظه سیناپسی مدل در حین مکالمه
   - **کالبدشکافی احتمال کلمه بعدی (Next-Token Predictor):** مشاهده نمودار احتمالات Softmax و تنظیم دمای خلاقیت (`Temperature`)

2. **🏎️ سوار کردن مغز عصبی روی ماشین خودران (Autonomous Neural Agent):**
   - شبکه عصبی چندلایه (`[8 -> 12 -> 8 -> 2]`) که ورودی ۷ سنسور لیزری (`Raycast`) و سرعت را دریافت کرده و فرمان چپ/راست و گاز/ترمز را صادر می‌کند.
   - قابلیت **قطع و وصل کردن مغز از بدنه**، **آموزش سریع نسل‌ها (Neuroevolution + Policy Guidance)** و **کاشتن موانع زنده با کلیک موس روی پیست**.

3. **🦀 بانک مغزها و موتور کد خروجی Rust (`rust_engine/`):**
   - ذخیره و بارگذاری مغزهای آموزش‌دیده
   - تولید خودکار کد `struct NeuralBrain` به زبان **Rust** با قابلیت کامپایل به **WebAssembly** و **PyO3 (پایتون)**.

## 🚀 اجرا

```bash
npm start
```
سپس آدرس `http://localhost:3000` را باز کنید.
